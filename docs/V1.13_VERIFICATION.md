## User visual acceptance — pending

Follow [the image guide](IMAGE_IMPORT_GUIDE.md) for native picker/drag-drop, shared object versus detach, photo alignment/visibility, fit/fill/stretch, warped transparent images, moved saved packages and clean Test Output. Direct native drag/drop and photo compositing acceptance remain user checks; the automated checks above are distinct from user-reported approval. Physical projector acceptance remains deferred.

Limits: one PNG/JPEG at a time, 128 MB input and 100 megapixels; normalize to at most 4096 on the long edge; 64 assets and 256 MB decoded/PNG-data project budgets. BGRA premultiplied sRGB pixels are cached per asset with GPU mipmaps per renderer. Imported PNG bytes remain in bounded memory until save/recovery; successful package saves/recovery copies include them. The owner canvas aspect starts at the chosen output aspect and is explicitly editable. Wide-gamut/HDR, animated images and multi-image import are outside this milestone.
