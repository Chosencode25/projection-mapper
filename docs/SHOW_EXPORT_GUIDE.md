# Export and collect a show

Choose **File → Export Video** to make an MP4.

1. Choose **Mapped Projector Output** for the saved projector layout. Use the projector's pixel size for direct playback on that output.
2. Choose **Unmapped Content Canvas** for one face or object's source and shared layers.
3. Set the resolution, frame rate, and start and end times. Enable **Include project song** to add the saved soundtrack.
4. Choose a new name and folder. You can cancel while the export runs. When it finishes, choose **Show in Finder** to open the destination.

Choose **File → Collect Show Assets** to move an editable show to another Mac. Save the new .projectionmap package, move it as a whole, and open it in Projection Mapper. Check the display and fixtures on the receiving Mac and install the fonts used by your text layers. The original open project stays in place.

The MP4 uses H.264 SDR with optional AAC soundtrack. The selected time range plays once. The last video frame can extend past the requested end by less than one frame. Lighting programming travels in the editable project.
