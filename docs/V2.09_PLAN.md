# v2.09 — Layers, Regions, and Text

Planning draft, November 11, 2026. Start from the tested local v2.08 build 27 source and portable format 13. Use a copy of [Winter Lights Playground](WINTER_LIGHTS_DEMO.md) for the rehearsal.

## 1. Stack visuals on a face or linked object

- Add a **Layers** section to the Edit inspector. Keep existing content as the base. Add, name, reorder, hide, duplicate, or remove overlays. Set opacity, blend mode, position, scale, and rotation. Treat a drag or slider gesture as one undo step.
- Start with Normal and Add blend modes, and a proposed limit of one base plus three overlays per content owner. Use the current effect, image, and video sources. Offer a static overlay or a collapsible timeline lane with the existing move, trim, and crossfade rules. In a sequenced overlay, gaps are transparent. At first, overlay transforms are fixed for the layer.
- Compose in the owner's shared canvas, then map the composite to its faces. Linked faces use one composition and clock. Preserve the existing base track, crossfades, and choreography. A choreography override continues to drive the base while authored overlays stay visible. Face appearance, cutouts, and output blackout still apply to the result. Calibration keeps its existing diagnostic view.
- Keep the song and existing video-audio rules in charge of audio. Overlay videos are muted. Share video frames across linked faces. Start with a limit of two simultaneous video sources per owner, counting both sides of a crossfade and any region video on that owner's faces. Surface conflicts in Edit when an authored overlap would exceed the limit. Keep the existing render path for owners without overlays or regions.

## 2. Add named regions and outlines

- In Edit, select a face and draw a named rectangle or polygon using the existing mask editing controls. Offer saved mask shapes as reusable copies that can be assigned and edited independently. Give each region a stable ID so renaming it keeps its timeline links.
- Add a region lane so a window center can play a video while its outline runs an independent effect. The owner's layers use shared-canvas coordinates. A region uses the selected face's local coordinates and inherits that face's perspective and final mask. Draw region content above the owner composition and use list order for overlapping regions. Define outline thickness as a percentage of the shorter side of the unwarped face so Edit zoom leaves it unchanged.
- Support region selection and outlines in Edit. Keep selection handles out of Show and Test Output. When removing a region or deleting its face, remove dependent clips in the same undoable edit. Test duplicate, reassign, undo, and reopen with a linked object and an existing mask hole.

## 3. Put titles, greetings, and countdowns on the timeline

- Add a **Text** source for a layer or region. Offer custom text, song title, and countdown, with font, size, alignment, color, and a layout box. Clip overflow to the layout box and the target's visible boundary. If a saved font is unavailable, use the system font and report the fallback in readiness.
- Use the song playhead for the first countdown. Set a target time or use a timeline marker. Show whole seconds rounded up while time remains, then show zero through the end of the clip. The same timestamp produces the same result during playback, scrubbing, and loops. Schedule-based countdowns can use the schedule clock once that milestone lands.
- Keep projected text inside authored clips. Show mode still presents playback and cue information in the operator panel.

## 4. Animate a singing face

- Add a singing-face source with an original face and a small set of distinct mouth shapes, including a neutral rest pose. Make it usable as a layer or inside a region. Use one stable face asset set that ships with the app or travels with the project.
- Give each singing face its own mouth-shape lane, aligned to the song waveform and existing lyric markers. Provide a shape picker at the playhead, with optional snap and a short loop for rehearsal. A visible face uses its neutral pose before its first key. Each keyed shape holds until the next key or the clip ends. Resolve the same shape on playback, seek, and loop wrap. Keep existing lyric markers available as timing references.
- Author the first rehearsal manually. Automatic lip sync is a later enhancement. Add timing import only when there is a known format and a sample to verify against.
