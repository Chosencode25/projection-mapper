# Lighting workspace rehearsal

Local preview: **v2.09/build 33**, the first dedicated Lighting workspace section. Applications still contains build 32 until Install is requested. Open the preview at `builds/lighting-workspace/ProjectionMapper.app`.

1. Open a show or choose **Project → New Show from Playground…** and set **Start in → Lighting**. The workspace switch above the project also opens **Lighting** from any existing show.
2. The right inspector also has **Output** and **Project** tabs for the existing readiness, output and project controls. Use **Setup & Monitor** to configure simulated controllers and fixture patches. A fixture's Group field assigns it to a named group. Existing projects retain their patches, groups and schematic positions. The plus menu above the fixture list adds a fixture with available compatible outputs; edit the proposed patch before applying.
3. Select a fixture in the left list or schematic. Select a group to control its fixtures together. The right inspector offers the controls those fixture types support. For mixed groups, it shows the first fixture of each type; changing a control applies it to selected fixtures of that type. **Resume Fixtures** enables manual audition; the SIMULATION label describes the current output foundation.
4. Turn on **Edit Placement** in the schematic to drag a fixture or strip endpoint. Placement changes are saved and undoable. The eye buttons hide fixtures only in this schematic. Fixture output remains governed by the shared transport and fixture controls.
5. Compose a look, enter a new look name and click **Capture Look**. Audition controls are runtime state; Capture Look saves programming into the project. Selecting a saved look lets you audition it, then place it at the playhead. Clear Manual Overrides to rehearse the timeline's authored fixture state.
6. The bottom timeline uses the same song, waveform, markers, zoom, Snap, Follow and loop controls as Edit. Lighting has an overview cue row plus individual fixture rows. Choose a captured look and use the plus button, or double-click a fixture lane to target that fixture. Select a cue diamond to edit time, movement lead/curve for moving heads, dimmer fade, or manual-only behavior in the inspector. Duplicate/Delete and Command-Z follow cue editing and shared project history.
7. Enable **Projection References** to see read-only projection tracks and choreography as timing references. Projection continues playing on the same clock even when those tracks are hidden. Switch Edit → Lighting → Show and verify mapping, song position and cue state remain consistent. Leaving a running Show for either authoring workspace asks to pause; the output window stays open.
8. Save and reopen. Check looks, cue timing, patches, groups and placement. Choose Test Window in the Output inspector and use Window → Show Output. Rehearse a short song loop with simulated fixtures, seek before/after a cue and confirm the intended fixture state reconstructs correctly. Returning to either authoring workspace must not create a second song clock.

User visual/listening acceptance is pending. First check panel sizing at your normal and minimum window sizes, fixture/group selection, placement dragging, mixed-group controls, cue selection and synchronized Test Mode playback. No screen control was used for this build. This schematic is not a photometric preview. Physical fixture/projector acceptance remains deferred.
