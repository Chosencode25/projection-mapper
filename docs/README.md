## Local folder layout

Source and the installed development app live in app/; project media lives in assets/.
Local working projects rescued during cleanup live in assets/local-projects/ and are excluded from Git.
Generated archives, check reports, one disposable cache and lightweight historical evidence live in builds/ and are excluded from commits.
The original ChatGPT mirror and synced sources remain read-only references.
