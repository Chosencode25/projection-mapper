## Implemented

- One programmatic borderless external fullscreen output with explicit Open/Close and Escape, separate from the resizable Test Window. Shared Metal scene/rendering and content/video/audio ownership; no new transport or player.
- External/extended/editor-screen eligibility, unique identity and live device checks before presentation. Display/discovery/mode/scale/position changes and sleep close output with reachable recovery messages. No automatic reopening or relocation; output selection/restoration does not start playback.
- Decoder/scene/fade/mask/identification updates reach physical output. Renderer initialization/command failures remain editor errors and close physical output. Editor-only decorations/photo are excluded.
- Full-output boundary/identity and nominal 60 fps frame/flash diagnostics with bounded submitted-frame cadence, blackout priority and Finish restoration. Machine-local bounded/versioned device/mode profiles include measured delay, notes and reserved future compensation; no timing compensation is applied in v2.01.
- Portable format remains **9**; device profiles, active output and diagnostic state are runtime/local settings. New Project closes physical output while preserving existing Test Window reset behavior. Project open/recovery closes output, pauses transport and disables audio.
- Current output controls, help, status and readiness reflect physical-output state. The intact bundled demo is now the history regression fixture; unrelated pre-existing canonical-demo deletions remain untouched.
