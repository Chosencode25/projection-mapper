# v2.13 Playlists, scheduling and Project Home

November 22, 2026. The user chose to bring playlists and scheduling forward after Show Mode, and requested a native Mac project browser. v2.12 external synchronization stays queued.

Project Home uses SwiftUI and programmatic AppKit and opens recent shows and drafts through the normal project loader. Preview drawings read saved mapping geometry. No new required resource is added to a project.

Playlist and schedule settings use a versioned local library separate from portable project format 16. Playlist entries reference saved project paths. Each playback handoff uses existing media staging and Show Mode preparation. Automatic schedule arming is session-only, with persisted occurrence IDs and bounded cutoff handling. This implementation supports one active playlist, sequential transitions and fixed clock rules. Sunset scheduling remains optional and pending.
