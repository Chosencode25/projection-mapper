## Rehearsal findings

Two early attempts found that the full-song loop could take the natural end-of-show branch. The candidate keeps loop and one-shot completion separate and tolerates the player stopping just before the expected boundary. A bounded decoder fallback samples the current show clock when a video loop or seek leaves the running player with no frame. In the paired 28-second comparison, missing requests fell from 128 of 781 to 27 of 780.

| Final 30-minute workload | Result |
| --- | --- |
| Render and playback | 53,913 frames at 1920 × 1080 with a 30 fps submission target. 74 complete soundtrack wraps and 88 missed submission slots. |
| Timing | GPU p95 2.73 ms. Submission interval p95 35.28 ms. The cumulative song clock trailed wall time by 13.79 seconds across the repeated seeks. |
| Resource use | 21.4% of one CPU core on average for the XCTest process. Sampled RSS peaked at 410 MiB and was 77 MiB after teardown. |
| Video availability | 1,148 of 49,480 required video-frame requests (2.32%) had no image at submission. Visible impact is a user rehearsal item. |
| Shutdown | Test Window and offscreen renderer released. The test checked that video owners were cleared and staged video files were removed. |

The isolated offscreen timing run used AVPlayer with audio output muted. GPU time is Metal command-buffer time. Measurements characterize this workload on this Mac. Physical optical, device, and audible sync remain user acceptance items.

The candidate bundle and extracted ZIP match all 11 application files and pass strict signature verification. Archive SHA-256 is 0853b1dc9b9f9d7966cf4dd03ba829134c059ef20297b8eb16077e332c5cbeb6. The candidate is ad-hoc signed. This Mac has no Developer ID Application identity for notarization.

The final Release run reported 401 tests across 44 suites with zero failures. It included full Encore video exports, package relocation and two complete consecutive playlist items. Four optional benchmarks were skipped, the measured soak ran separately and two established visible-window checks were excluded.
