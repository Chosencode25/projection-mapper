1. Generate a reusable 512×512 diagnostic texture: 8×8 checkerboard, grid, border and distinct corner colors. New projects use the grid; retain solid fill as an inspector option and renderer regression fixture. No file import (v1.08).
2. Derive a projective unit-square-to-quad matrix in Double precision from the four normalized corners. Validate finite bounded coordinates, strict convexity and invertibility. Pass the inverse matrix to Metal; divide homogeneous texture coordinates per fragment so there is no two-triangle seam.
3. Include content choice in immutable shared scene snapshots; update existing preview/output on corner or content edits. Preserve normalized fitting, on-demand rendering, preset/reopen/reset and dirty-state behavior. Cache the texture per renderer, not per frame.
4. Crossed, concave, collapsed or numerically unsafe geometry clears to black without retaining stale content. Show an editor warning and keep handles usable. Inspector corner selection supports recovering overlapping handles. Reject corners with absolute consecutive-edge cross product ≤0.000001 in normalized coordinates, and projective poles/unsafe transforms.
5. Test independent known transforms, straight-line/projective continuity, unsafe geometry and recovery, actual GPU texture orientation/warping/black output, shared updates and preset sizes. Run complete Debug/Release regressions with pinned toolchain; visually check skewed grid, clean output, invalid/recovery and portrait fitting. Record evidence, deliver signed Release copies to builds/v1.07/ and app/ProjectionMapper.app, preserve previous builds, commit/push feature branch and tested main. No automatic bundle bump/tag/release/archive.
