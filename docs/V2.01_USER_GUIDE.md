# Projection Mapper v2.01 — Local Output Guide

Local v2.01/build 14 keeps the V1 mapping, timeline, media, undo and portable format 9 workflow and adds one external fullscreen output. See [V1 guide](V1_USER_GUIDE.md) for authoring. Physical projector acceptance is pending; see [verification and checklist](V2.01_VERIFICATION.md).

## Open output

1. Quit an older running copy and open `app/ProjectionMapper.app`.
2. Connect the external display/projector. In macOS Displays settings, use an extended display rather than mirroring. Keep the editor on a different display.
3. In the Project inspector's Output Target controls, Refresh Displays and select the external display. Built-in, mirrored and editor displays are unavailable. Check its reported resolution, backing scale and refresh; these are reported metadata, not measured projector latency.
4. Click **Open Projector Output**, or Window → Show Output (Control–Command–O). Selection alone does not open output, start playback or enable audio. The clean scene uses your existing mapped faces, masks and shared content.
5. Use **Close Output** to remove the output window. Escape closes it when that window has focus. **Blackout** draws black while keeping output open; it does not stop playback or mute audio. Stop and audio mute remain separate controls.

Test Mode remains available: choose Test Window and explicitly Show Test Output. Its resolution presets and normal resizable window are unchanged. One clean output destination is open at a time; editor preview remains independent. New Project preserves an already-open Test Window, while closing physical output. Opening/recovering another project closes output and starts paused, with audio disabled.

## Display changes

Display configuration changes, unplugging, sleep, mirroring or moving the editor onto the selected output display close physical output. An editor warning explains that playback may still be running. Stop/mute if needed, refresh/select the intended display and explicitly reopen output. The app does not open output on a substitute screen or resume automatically after reconnect/wake. Layout coordinates and remembered display preference are retained.

After mode/aspect/orientation changes, inspect physical alignment again. Normalized geometry is preserved rather than silently rewritten. The app does not change your system display settings or control projector power/input.

## Calibrate the full output

Expand **Output Calibration** below Output Target after selecting an external display. Open projector output to enable its temporary diagnostics:

- **Output Boundary / Identification** shows a full-output grid, device name, resolution and orientation labels. Existing surface calibration remains available separately for face-local alignment and object joins.
- **60 fps Frame / Flash Fixture** shows a nominal 60-frame-per-second elapsed-time counter and a one-frame white flash each nominal second. Actual submitted cadence is reported in the editor. A display running at another cadence may skip/repeat nominal fixture frames; this is a measurement aid, not a claim of locked display timing.
- **Finish Output Calibration** restores the current clean project scene without changing mapping, saved content or playback. Blackout also suppresses diagnostic labels and patterns.

Enter measured delay in milliseconds (0–2000) and notes identifying the equipment/method. Measuring optical latency requires a suitable camera/sensor and a reference; submission cadence alone is insufficient. Store measurements only when actually taken.

The compensation value (−500…+500 ms) is saved for v2.02 music synchronization and **does not alter current playback**. Positive compensation will evaluate visual content later on the authoritative song timeline to compensate a late projected image. No music-sync claim is made in v2.01.

Save Device Calibration stores a profile on this Mac for a unique device identity and its resolution/refresh. A changed mode produces a remeasurement warning; a different device cannot inherit the profile by name. Profiles, temporary patterns and output-open state are excluded from portable project packages. Measurement notes are limited to 2000 characters.

## First physical check

Use a simple project first, then the bundled V1 demo. Confirm output covers only the chosen display, the editor remains reachable, and no editor handles/photo or error messages appear. Check corners, orientation, masks, connected-face joins and video ownership. Exercise Blackout/Restore, Finish Calibration and Close/Escape. Then check unplug/replug, sleep/wake and a display-mode change, confirming explicit reopening is required each time.

Record projector model, Mac/OS, connection/adapter, mode/refresh and results in the verification checklist. The current automated tests do not establish physical fullscreen presentation, optical delay, audible synchronization, Intel runtime or hours-long stability.

This local build is ad-hoc signed, supports macOS 15 or later, and is not Developer ID signed/notarized. Nothing from v2.01 is uploaded to GitHub.
