# v2.09 verification

November 11, 2026. Projection Mapper v2.09 build 28 uses portable project format 14. Xcode 27.0 beta 5 (27A5237l) built and tested the Release app. The local app copy under `builds/v2.09/` matches the tested product and passed strict signature verification. Its executable contains Apple Silicon and Intel slices. The tests ran on Apple Silicon.

## Automated results

- 342 tests passed, four opt-in benchmarks were skipped, and two legacy tests that present native windows were excluded.
- The new checks covered ordered normal and additive blending, a face-local outline with a preserved mask hole, distinct rendered countdown and mouth states, and repeatable seeking. They also covered a format 13 migration, region deletion and undo, and shared muted video requests across linked faces with an overlap limit.
- Winter Lights Encore opened with its packaged media and saved and reopened with the same project data. The singing ornament uses manually authored keys on an instrumental track.
