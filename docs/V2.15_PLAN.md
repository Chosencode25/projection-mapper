# v2.15 Export and Portable Delivery

## Export Video

Mapped Projector Output renders the saved projection layout with visible faces, corner transforms, masks, joined input maps, layers, face regions, and saved master brightness. Unmapped Content Canvas renders one selected face or object's source and owner layers into a full-frame rectangle. Face-specific geometry, masks, input mappings, and regions are omitted from the canvas export. Both modes share the existing Metal renderer and timeline evaluation.

The default dimensions come from the selected display or the saved Test Window resolution. Choose a preset or custom even dimensions from 16 to 4096 pixels per edge, with a maximum of 8,847,360 pixels per frame. The chosen dimensions define the output aspect. Choose 24, 25, 30, 50, or 60 fps and a start and end between zero and one hour. The default duration is the project timeline end or 10 seconds for an untimed project.

The renderer evaluates absolute show times starting at the selected start. The MP4 begins at timestamp zero with a fixed cadence and rounds up to one final whole frame when needed. The requested end is exclusive. The saved timeline clip ranges, rates, transitions, and video source loops are used. Export runs a single timeline pass. Live song repeat, live blackout, calibration patterns, and projector latency compensation remain playback controls. Output uses SDR Rec.709 H.264. Optional AAC comes from the saved song at its original level and ends at the requested end or the song end, whichever comes first. Video-clip audio and fixture output remain in the editor.

Both operations validate media and report progress. The export size estimate reflects target bitrate. The project song is encoded as stereo AAC at 48 kHz. The MP4 carries the project and revision identifiers, mode, canvas owner if applicable, dimensions, cadence, frame count, range, and audio policy. Publication uses a same-volume atomic rename that rejects occupied destinations. Cancellation and failure preserve existing files.

## Collect Show Assets

The File command creates an independent editable .projectionmap package from a snapshot of the open show, including unsaved edits. Package format 16 carries the project's videos, images, reference photo, soundtrack, mapping, timeline, cues, looks, and presets. Assets are validated before publication. The editor and autosave remain associated with the original document.

Saved display and lighting settings travel as configuration. Recheck fixtures, displays, timing, and fonts on the receiving Mac. Font names are retained and the renderer uses its normal fallback if a font is unavailable. App-local Playgrounds, playlists, schedules, and font files live outside a single show package.

## Acceptance

The automated checks use the pinned Xcode 27.0 beta 5 (27A5237l). They cover export modes, mask pixels, frame cadence, video source ranges, soundtrack trimming, cancellation, destination conflicts, and reopening a collected package from another folder. User visual and listening checks and downstream player compatibility remain pending.
