# v1.15 — V1 completion

Prepared release notes; **no release/tag/asset publication has been authorized or performed**. Private repository visibility remains unchanged.

Projection Mapper V1 is a native Mac workspace for mapping built-in effects, images and video onto faces and connected objects, arranging them on an object timeline, and saving portable projects. Output is a resizable Test Window sharing the renderer with the editor. Fullscreen projector output and physical acceptance remain scheduled for v2.01.

## New in this milestone

- Undo/redo project edits with stable geometry/object/asset/clip identities, coherent mapping/mask/slider transactions, retained original media, save-aware dirty detection and bounded session history.
- Readiness snapshots with actionable blockers/warnings/information for geometry/masks/joins, live/look/timeline assets/ranges, decoder problems, audio selection and current output scope. Checks do not start playback.
- Temporary selected-owner identification with reachable Finish and preservation of mapping, transport, calibration and blackout priority.
- Scrollable timeline controls on narrow windows, native text undo routing, accessible actions, protected demo opening, welcome/help/About and a code-generated app icon.
- Portable mixed-content demo with generated house reference illustration and masks, connected three-face object and independent looping video; each opened demo has its own document identity and starts unsaved/paused/audio-disabled.

## Development distribution

Bundle 1.15/build 12, portable format 9, minimum macOS 15. Universal arm64/x86_64 app, locally ad-hoc signed. This is a development artifact; Developer ID signing and Apple notarization have not been established. Intel/older-macOS runtime, user visual/listening checks and physical projector operation are unverified. The repository stays private.
