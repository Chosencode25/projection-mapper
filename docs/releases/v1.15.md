# Projection Mapper V1 — v1.15

The complete V1 mapping workspace for Mac: map built-in animations, images and videos onto independent surfaces or connected object faces, arrange effects on an object timeline, and save portable projects. V1 output is a resizable clean Test Window using the same Metal renderer as the editor.

## Included in V1

- Multiple surfaces with editable corners, perspective mapping, masks and cutouts, geometry locks and editor-only reference photos.
- Connected object faces with shared content, timing and video playback; continuous input regions, repeat mode, edge alignment and deliberate seams.
- Animated generators, reusable looks and palettes, brightness/fades, calibration and blackout.
- PNG/JPEG image import and SDR H.264/HEVC MP4/MOV video import, placement, replace/relink and explicit video-audio mute/routing controls.
- Object timeline with effect/image/video clips, precise source ranges, move/trim/loop, shared playback, seeking, zoom, snap and follow.
- Portable .projectionmap saves with included media, recovery, format 9 validation and migration from formats 1–8. Projects reopen paused with audio disabled.
- Project undo/redo, readiness diagnostics, temporary object identification, protected bundled demo, welcome/help and app icon.

## Download and install

Download **ProjectionMapper-v1.15-macOS-universal.zip**, extract it and copy ProjectionMapper.app to your preferred app folder. Quit an older running copy first. Open Help → Welcome or Open V1 Demo; use Save As to create your own project. The ZIP includes INSTALL.txt, the V1 guide and build identity. SHA256SUMS.txt verifies the archive and companion guide/identity.

Version **1.15/build 12**, macOS **15 or later**, universal **Apple Silicon and Intel** executables. Built and tested with **Xcode 27.0 beta 5 (27A5237l)**. Tested app source: **60e838d3f7f5eabac830620f90f93502ceb9f602**; the release tag also includes finalized documentation.

This is a full GitHub release, not a prerelease. The repository remains private. The app is locally ad-hoc signed, **not Developer ID signed or Apple-notarized**; macOS may require approval for a downloaded copy. Follow your Mac's security prompts and only approve this verified download if you trust its source.

## Verification and limits

**269 correctness tests passed in both Debug and Release**, with zero failures and runtime warnings. Four optional benchmarks were skipped in those runs; two visible-window checks were excluded. Separate sustained mixed-HD playback and full-resolution effects profiles passed. Strict signatures, universal slices and every packaged app file were checked against the tested Release product. No app code changed during release finalization.

Runtime testing used Apple Silicon/macOS 27. Intel and older supported macOS execution, routine user visuals/listening, actual audio-device unplug and perceived audiovisual sync remain unverified. Dense overlapping particles at 4K exceeded the measured 60 Hz budget; reduce density/overlap or use Full HD for heavy scenes. Profiling is bounded and offscreen, not a guarantee for every project.

Fullscreen physical projector output/calibration starts in v2.01. Music/song transport, waveforms, Christmas-show sequencing and external lighting integration are future V2 work.
