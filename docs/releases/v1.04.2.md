# v1.04.2 — First Rectangle

Test Output now draws a centered orange rectangle on black through compiled Metal shaders. Four normalized corners keep scene geometry independent of window size; the output fits HD, Full HD, 4:3, Portrait, and 4K presets with black margins. Simulated resolution remains separate from native drawable dimensions.

This release also includes the resolution preferences, aspect fitting, saved window frame/recovery, and Show Output/Editor shortcuts developed after v1.03.1. Output stays closed at startup, and native close/reopen and minimize/restore preserve expected behavior.

## Validation

- Xcode 27.0 beta 5 (27A5237l), matching Metal Toolchain, Swift 6; macOS 15.0 minimum.
- All 43 tests passed in Debug and Release: actual GPU pixels, coordinate conversion, initialization errors, live presets, native window sizing and regressions.
- All five presets visually checked; window redraw checked. Final Release app version/status and rendering confirmed.
- Apple Silicon Release app, version 1.04.2/build 4, with verified ad-hoc signature.

Download the ZIP, extract it, and open ProjectionMapper.app. The companion file provides its SHA-256 checksum. This is a development prerelease without notarization. Older macOS versions and Intel hardware remain runtime-untested.

The rectangle is temporary diagnostic content. Shared editor rendering comes in v1.04.3; editable surfaces, handles, perspective warping, media, and saving remain later milestones. Projector implementation/physical testing remains deferred. A 4K preset label is not a measured full-resolution performance claim.
