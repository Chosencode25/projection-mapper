# Projection Mapper V1 — v1.15.1

Corrects the Show inspector in the full V1 release. v1.15 implemented readiness and global video-audio controls but did not display them in this tab. **Show now exposes Check Project, Identify Selected/Finish, and Video audio with Enable Audio, master volume and output-device selection.**

This patch retains the complete V1 feature set, Test Window output and portable format 9. Existing projects and media remain compatible. It replaces v1.15 as the recommended download; the original tag, release and assets are preserved.

## Install

Download **ProjectionMapper-v1.15.1-macOS-universal.zip**, extract it, quit any older running Projection Mapper and copy ProjectionMapper.app to your preferred app folder. Version **1.15.1/build 13**, **macOS 15 or later**, universal **Apple Silicon/Intel**. SHA256SUMS.txt verifies the archive and companion guide/build identity.

The full release remains in the private repository. The app is locally ad-hoc signed, **not Developer ID signed or Apple-notarized**. macOS may require approval for a downloaded copy; follow its security prompts and approve only a verified download you trust.

## Verification

The corrected app code passed **269 correctness tests in both Debug and Release**, zero failures/runtime warnings, using **Xcode 27.0 beta 5 (27A5237l)**. Four optional benchmarks were skipped and two legacy visible-window checks excluded. The subsequent version/build metadata change was rebuilt in Release; no additional app behavior changed.

Authorized short onscreen checks verified repaired control reachability, readiness without autoplay, identification/Finish, mapping and timeline undo/redo, mixed effect/video/image transitions, clean output, calibration/blackout, compact layout, video relink and portable save/reopen. Audio route/volume/enablement controls were exercised, and projects reopened paused with global audio disabled.

The long real-use session was explicitly skipped. Audible mute/pause/stop, perceived audiovisual sync/pitch and physical device unplug remain unverified; only built-in speakers were exposed. Intel/older-macOS runtime is unverified. Fullscreen projector output and music/show sequencing remain V2. Heavy overlapping particles at 4K retain the documented performance limit.
