# v1.02 Preview — Output Selection

Choose Test Window or an independently usable connected display from the toolbar or inspector. Inspect render dimensions, desktop points, scaling, and reported refresh information. Explicit preferences survive relaunch; missing or ineligible displays fall back to Test Window without erasing the remembered target.

Includes display-change discovery, editor-screen eligibility, mirroring explanations, manual refresh, shared status, and a preview outline matching the selected aspect ratio. Output changes preserve project data. About and the footer use bundle version metadata.

## Validation and limits

- Xcode 27.0 beta 5 (27A5237l), Swift 6, macOS 15.0 minimum.
- 21 automated tests passed, including all five v1.01 regressions.
- Local editor and standalone Release app verified on Apple Silicon/macOS 27.0; minimum-size and long-name portrait layouts checked with synthetic data.
- No external monitor/projector was available. Physical display metadata, hot plugging, mirroring, and external preference restoration remain pending acceptance.
- This preview is published from the feature branch. Main and the v1.01 release remain preserved; the final v1.02 milestone awaits physical verification.

Download the Apple Silicon ZIP, extract it, and open ProjectionMapper.app. The archive uses ad-hoc development signing and is not notarized. The companion file contains the SHA-256 checksum.

Selecting Test Window does not open another window yet. Output windows arrive in v1.03 and rendering in v1.04. Media import, mapping, and saving remain later milestones.
