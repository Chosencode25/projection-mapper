The first development milestone of Projection Mapper is a native Mac editor skeleton, ready for the next stage of output selection.

### Included

- Toolbar, surface sidebar, empty 16:9 preview canvas, inspector, and status bar.
- Editable project name and in-memory project state.
- New Project, Close, and Quit with Cancel/Discard protection.
- Sidebar/inspector toggles, keyboard shortcuts, editor reopening, and About version information.

### Verification

- Built and launched with **Xcode 27.0 beta 5 (27A5237l)**.
- Five state tests passed; no failures or skipped tests.
- Default, minimum, and larger window layouts inspected.

### Downloads

`ProjectionMapper-v1.01-macOS-arm64.zip` contains the local Apple Silicon development app. Extract it and open `ProjectionMapper.app`. It is ad-hoc signed and has not been notarized for public distribution. Runtime checks used macOS 27.0; the deployment target is macOS 15.0.

This milestone keeps projects in memory. Rendering, media import, projection surfaces, test/projector output windows, and saving are scheduled for subsequent milestones.

To build from source, open `app/ProjectionMapper/ProjectionMapper.xcodeproj` in the pinned Xcode version, select ProjectionMapper and My Mac, and press Command–R.
