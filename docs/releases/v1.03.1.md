# v1.03.1 — Basic Test Window

Open a separate, movable, resizable black Test Output window alongside the editor. Toolbar, inspector, and Window menu controls open or close it. Repeated Open Output brings forward the same window and restores it after minimizing. Native close updates shared status and preserves the editor/project.

New Project preserves the open test window. Successful editor close and quit close output too; canceled discard confirmations leave both windows intact. Output stays closed on launch. Only Test Window can open output; projector implementation and physical checks are deferred at the user's request.

## Validation

- Xcode 27.0 beta 5 (27A5237l); Swift 6; macOS 15.0 minimum target.
- All 28 tests passed, including seven real AppKit window tests and all 21 earlier regressions.
- Local two-window, minimize/reopen, native/menu close, New Project, editor close, and quit behavior checked.
- Apple Silicon Release app, version 1.03.1/build 3, with verified ad-hoc signature.

Download the ZIP, extract it, and open ProjectionMapper.app. The companion file provides its SHA-256 checksum. This is a development prerelease, without notarization. Older macOS versions and Intel hardware remain untested.

The output is intentionally black. Resolution presets/aspect fitting follow in v1.03.2; window persistence/polish in v1.03.3; rendering in v1.04. Mapping, media import, and project saving remain later milestones.
