## Implementation

The editor SwiftUI wrapper and Test Output receive the same scene value and use MetalSceneView/MetalRenderer. Each view retains its own renderer and drawable resources. Editor caption and border remain outside the clean rendering surface. Both views fit the selected output aspect independently of native drawable dimensions.

This scene is a fixed diagnostic rectangle; editable surfaces begin in v1.05. The drawing implementation remains usable by future projector output.
