# v2.05 — Music and Show Transport Verification

Bundle 2.05/build 20. Portable format 11. Developed on `codex/v2.05-song-transport` from the tested v2.02 baseline, with local USB-DMX work isolated.

## Automated checks

- A generated PCM click track exercises asynchronous import, bounded waveform generation, save/reopen without the source file, and undo of song removal. A separate test checks that format 10 opens without a song.
- Muted playback exercises the system audio clock, two loop wraps, a fixture cue before and after wrap, and Stop. The test compares the fixture's effective state and the scene's timeline position at each sampled update. This measures evaluated state agreement, separate from speaker, video decode, display and fixture latency.
- A synthetic compensation check exercises positive and negative offsets and clamping at song and loop bounds.
- Focused Debug verification passed nine soundtrack and fixture tests with Xcode 27.0 beta 5 (27A5237l).

The full Release suite passed **321 tests** with zero failures and zero recorded runtime warnings. Four optional benchmarks were skipped and two legacy visible-window tests were excluded. Both architectures are present, strict signing checks passed, and the extracted ZIP matches the Release build. The local app, ZIP, click-track rehearsal project and result summaries are under `builds/v2.05/` in the main project folder.
