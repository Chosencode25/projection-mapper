## Delivered

- Animated gradient, moving lines and moving checkers alongside existing grid/solid content. Two literal colors belong to the selected standalone source or shared object source.
- Inspector playback section explicitly controls all animated faces: Play/Pause, Restart and 0.25×/0.5×/1×/2×/4× speed. Default/reset transport is paused at zero. Restart preserves playing/paused state; speed changes preserve the current phase.
- One immutable elapsed-time clock anchor is supplied to editor and Test Output. Each render evaluates one explicit time for all faces, independently of frame count/view refresh. Basic effects have an eight-second phase cycle at 1×. Same-time GPU evaluation is deterministic; native presentation times can differ slightly between windows.
- Continuous samples shared input coordinates; Repeat samples the whole effect on every face. Linked faces share settings. Duplication/detachment copy settings according to established owner policies and retain the global phase; editing the resulting independent owner does not affect its original.
- Playing valid visible animated scenes use the native MTKView display loop at a requested 60 Hz. Static/paused/empty/invalid scenes remain on demand. Existing hidden/minimized/occluded/closed availability gates pause drawing. Resumed views sample the shared current phase, rather than advancing a local frame counter.
- No generated texture or particle simulation allocation per frame. Procedural fragment evaluation uses existing geometry/pipeline and bounded uniforms. Actual display FPS and representative performance profiling remain later acceptance work.
- Runtime transport does not change project timestamps, dirty/discard state, selection or geometry. Content/color edits remain project changes.
