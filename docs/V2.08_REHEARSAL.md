# v2.08 — Holiday Choreography Rehearsal

Open **Holiday Chorus Rehearsal.projectionmap** from the local v2.08 build folder. Open **Test Output** and use **Show → Fixtures** for the simulated lights. The click track loops from 3 to 7 seconds.

1. Play the loop. Snow falls across the three linked projection faces. The fixture chase runs from 3 to 5 seconds, and the projection fades from snow to candy-cane stripes from 5 to 6 seconds.
2. Pause and scrub to **5.5 seconds** to see the fade midpoint. Scrub back to 4 seconds and check the fixture chase step. Repeat the loop to check that the same positions reproduce the same pattern.
3. In Edit, select a projection owner and choose **Holiday Presets** in Effect Presets. Capture the result on a clip to use it on the timeline. The selected owner's mapping and masks determine its placement.
4. Choose **Choreography** in the timeline toolbar. Select Fixtures or Projection, add and order targets, and choose Forward, Reverse, Bounce or Wave. Wave positions use the normalized X and Y fields and show in the diagram. Choose a color set or a project palette, set timing and save. Select the clip in the Choreography lane to adjust timing or targets.
5. To add a projection fade, select the incoming clip and choose **Transition**. Apply a duration to overlap it with the prior clip, or use **Cut**. Use **Clip Palette Color** to set a color on either clip and fade between those saved looks. If both clips use video, the incoming clip supplies embedded audio during the overlap when video audio is enabled.
6. In Markers, select a Beat and turn on **Downbeat** to mark a bar start. In Edit or Show, choose **Beat Queue → GO · Next Bar** or choose a named lighting look. The queued item and its time appear in Show. Cancel the queue from the same menu.

Chases and waves use discrete steps. Projection clip crossfades and the existing moving-head dimmer fades are continuous. Audio reaction remains an optional follow-on. Physical fixture and projector acceptance remain separate from this Test Mode rehearsal.
