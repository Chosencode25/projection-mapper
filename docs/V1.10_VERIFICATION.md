October 5, 2026. Bundle 1.10/build 7. Local delivery only, explicitly authorized after backing up v1.09 source to GitHub main at 9e64c0a. No v1.10 commit, push, tag, release or asset upload. Exact required Xcode 27.0 beta 5 (27A5237l), macOS 15.0 deployment target.

## Implementation

- File > Save Project (Command-S), Save Project As (Shift-Command-S), Open Project (Command-O), Open Recent, and Recover Unsaved Project; Finder document registration and represented document URL/title.
- Version 2 .projectionmap directory packages contain manifest.json and reserved assets/. Persistent identity, ordered standalone/grouped faces, owners, geometry, input maps, links/seams, Continuous/Repeat mode, tags, colors, six generator types/settings/seeds, presets, timestamps and output preferences round-trip. Playback/selection/window state is excluded. Loaded projects start paused at zero with fresh clocks.
- Validate collections, unique IDs, owner/membership/link references, coordinates, settings and enum values before replacing the session. Preserve editable geometry/join diagnostics. Missing/ambiguous physical UUIDs fall back to Test Window. Manifests are bounded at 16 MiB; faces/objects at 1,000, presets at 100, links at 10,000 total. Package/manifest/asset symlinks are refused when reading or copying their respective locations.
- Save stages and validates a sibling package, then uses atomic rename for a new destination or Darwin RENAME_SWAP to exchange existing directories. An injected pre-commit failure leaves the last good package/baseline/URL intact and cleans staging. Refuse overwriting unrelated or malformed folders. Save As preserves reserved assets and stable IDs.
- Dirty state compares declarative project data to the saved baseline, excluding modifiedAt. Unwritten custom initial content remains protected. New/Open/Close/Quit use Save/Discard/Cancel; failed/cancelled saves never authorize continuation. Open validates before showing the prompt.
- Two-second debounced recovery, including untitled projects, in ~/Library/Application Support/ProjectionMapper/Recovery. Retain ten valid project copies. Invalid copies are ignored, not automatically deleted. Startup/menu offer Restore/Later/Delete. Recovery stays dirty; successful Save or explicit discard clears its copy. A failed save retains it. Preserve a chosen recovery snapshot through the lifecycle prompt.

Schema 1 migration is an initial-format compatibility fixture adding missing presets/output defaults. No older public project-file format existed. Future looks/palette bindings, masks, media/reference assets and audio extend the schema at their assigned milestones; V2 references these stable layout IDs.

## User visual acceptance

Routine visual checks belong to the user; no screen control was used. Native Save/Open panels, Finder opening, recent menu and lifecycle/recovery sheets are compiled but their onscreen interaction is not claimed as verified. Suggested checks:

1. Create grouped and standalone animated faces, save a preset, Save, then Save As. Reopen both files; names, corners, ownership, input regions, effects and presets should return. Playback starts paused; seek/play should preserve joined motion.
2. Edit, then try New/Open/Close with Cancel, Discard and Save. Cancel keeps the edited project; cancelling a Save panel also keeps it. A successful Save permits the requested action.
3. Edit an untitled project, wait a few seconds, and use File > Recover Unsaved Project. Restore should show unsaved status and paused playback; Save should clear recovery. Later keeps the copy and Delete removes only the selected copy.
