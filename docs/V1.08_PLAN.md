Implementation decisions:

- Surface layout stores output corners, visibility, object reference and input region. Standalone content has a stable source identity; an object owns one shared source. Immutable draw snapshots resolve ownership and draw back-to-front.
- Group checked faces uses frontmost checked face content, preserves output corners, assigns side-by-side canvas regions and aligned neighbor links. Tags only select faces; they do not change ownership.
- A member-face duplicate retains the object source and input region; whole-object duplication rewrites IDs/links and copies its source independently. Detach copies the current source and effective input mapping/visibility. Empty objects are removed when their last face is detached/deleted.
- Input regions use bounded origin/size, quarter-turn rotation and mirroring. Edge joins compare endpoint coordinates including reversal and scale. Alignment moves only the second face input; invalid joins remain editable diagnostics. Explicit seams are recorded. Full 3D reconstruction is excluded.
- Static renderer uses one diagnostic texture per renderer rather than per face. Invalid geometry/input suppresses only that face; empty collections clear black. Output resize/reopen/preset changes retain the entire project.
