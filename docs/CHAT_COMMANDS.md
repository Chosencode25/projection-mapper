# Project chat commands

Saved November 17, 2026 as a proposed shorthand reference. We can revise these together. These are chat instructions for working on this project, not app keyboard shortcuts.

| Command | Intended meaning |
|---|---|
| **Build** | Implement the next agreed part, run automated checks and update progress. |
| **Fix** | Investigate, fix and verify the issue you describe. |
| **Plan** | Save a specific implementation plan without building it. |
| **Brainstorm** | Explore ideas together without changing files. |
| **Status** | Report completed, tested, pending and planned work. |
| **Test** | Prepare the verified app and a short walkthrough for your checks. |
| **Install** | Install the latest verified local build in Applications, preserving the previous app. |
| **Remember** | Record an agreed project decision in the appropriate docs. |
| **Park** | Preserve work locally and document where to resume. |
| **Backup** | Explicitly authorize committing and pushing the current project work to GitHub, including an exception to the milestone-only rule. No release publication. |
| **Usual** | Implement the agreed part, test it, update docs, preserve the previous app and install the verified build. GitHub delivery follows the existing milestone rules. |
| **Publish** | Prepare a release and its reviewable artifacts for your final approval before publication. |

Use these when clearly giving an instruction; merely mentioning a word is not an action request. You can add context, such as “Fix the playground chooser” or “Plan the lighting workspace.” If the target is unclear, use the current agreed task or clarify before taking an unrelated action.

Existing project rules still apply: pinned Xcode, local intermediate work, user-performed routine visual checks, preserved history and read-only references. Test means automated verification plus preparation for your visual checks; screen control remains reserved for investigating a specific expected bug. Saving this reference does not itself authorize a backup, installation or release.
