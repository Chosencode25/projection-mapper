## 1.11.1 — Appearance, crop and flips (implemented/automatically verified)

Add typed opacity (0–1), brightness (0–2, multiply RGB then clip to 0–1), normalized crop (positive bounded rectangle), and horizontal/vertical flips. Defaults are full crop, no flips, opacity/brightness one. Blend straight-alpha content back-to-front; apply brightness after evaluating content, then opacity to alpha. Zero opacity contributes no pixels. Content colors/settings and output corners remain unchanged.

Standalone faces own appearance. Objects own shared appearance; member faces inherit unless an explicit full appearance override is enabled. Enabling an override copies the effective object settings without a visual jump; disabling it returns to inheritance. Overrides replace, rather than multiply, object values and are visibly marked as potentially breaking joins. Apply a shared content crop/flip to the object's canvas before it is laid out across faces: inverse sampling is crop × flip × inputMap × inverseHomography, preserving equal linked input coordinates. Repeat mode still repeats the whole cropped/flipped canvas. Overrides use the same owner-coordinate convention.

Grouping adopts the frontmost selected face's effective appearance and returns members to inheritance, matching the existing shared-content policy. Attaching adopts the destination object's controls. Detach/ungroup bake effective appearance into the independent face, preserving sampled content and geometry. Duplicates preserve appearance/overrides with independent identities.

Add clearly scoped inspector controls and validated numeric crop editing. Extend package schema to 3; migrate schema 1/2 by inserting default appearance while retaining IDs/content/layout. Saved baselines, recovery and shared preview/output snapshots include new persistent values. Existing native file commands remain intact. Do not bump bundle 1.10/build 7 for this intermediate slice.

Verify inherited/override edits, bounds/nonfinite rejection, composition/order, grouping/attach/detach/duplicate policies, schema migration/save/recovery, unchanged layout/playback/presets, GPU blending/brightness/clipping/zero opacity, crop/flip sampling and joined animation pixels. Deliver verified local app in app/ and builds/v1.11.1/; user checks overlapping faces and inspector scope.

## 1.11.2 — Editing protection (implemented/automatically verified)

Persist output-geometry locks on faces and objects. An object lock protects every member without changing individual face locks; unlocking it restores the previous member lock states. Block corner drag/nudge, geometry/full-face reset, deletion and whole-object movement while effectively locked. Selection, unlock, naming/tags, visibility, content/appearance, explicit input-map/link/membership edits and duplication remain available. Detach bakes an effective object lock into the face; duplicates retain locks. Input regions are content mapping, separate from locked output corners.

Translate all member output corners by one clamped offset per action. Use the full member bounding box to bound offsets to 0–1, preserving relative placement, input regions and links. A locked member blocks the whole transaction. Provide object-inspector move controls, focused arrow/Shift nudging and a center handle for object dragging. Locked handles are visibly distinct; reconfiguration cancels in-progress drags when a lock becomes active. Text-field focus keeps normal native keyboard routing.

Separate reset scopes: output geometry only; opacity/brightness only; crop/flips only; generator settings/colors only; content defaults; and explicit full face controls/output. Standalone full reset preserves face/source IDs, name/tags/order, input mapping, membership and links, while restoring corners, visibility, appearance and default content. A grouped full-face reset restores face-owned geometry/visibility and clears its appearance override, without changing shared object content or input layout. Face content/generator reset applies only to standalone faces; object reset controls clearly affect shared content. Appearance/crop resets on grouped faces require an override. Generator reset retains effect type and clocks; content reset uses diagnostic grid with default colors/settings, preserving source ID. No runtime clock reset is implied.

An explicit object input-layout reset arranges its current member regions side by side with default orientation while preserving membership, link identities/directions/seams and output corners. It can introduce visible join diagnostics for custom links. This is the sole reset in this slice that changes shared input layout. Full-face reset and shared input-layout reset have descriptive native SwiftUI confirmation dialogs.

Extend saves to schema 4 with schema 1–3 migration defaults (unlocked). Keep the bundle at 1.10/build 7 and intermediate work uncommitted/off GitHub. Verify lock enforcement in state/native handlers, bounds/transaction preservation, reset isolation, identity/clock preservation, migration/save/recovery and matching GPU output. Deliver local app in app/ and builds/v1.11.2/; user performs routine visuals.
