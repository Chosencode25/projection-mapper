## Scope and limits

- Test Window is the only implemented output mode. External destinations remain discoverable, but Open Output is unavailable for them and the inspector explains that projector output is deferred.
- Fixed simulated target: 1280 × 720. Initial test content size: 640 × 360 points; minimum 320 × 180 points. The black content fills the resizable window; resolution presets/aspect fitting arrive in v1.03.2.
- Persistent window geometry and navigation polish remain v1.03.3; Metal rendering remains v1.04.
- Per the user's October 5 decision, projector implementation and physical external-display testing are deferred and do not block the Test Mode release. Earlier v1.02 hardware limitations remain unverified.
- Runtime testing used Apple Silicon/macOS 27.0. Intel and older supported macOS versions were not runtime-tested.
