# v1.03.1 — Basic Test Window

Scope approved October 5, 2026. Projector implementation and physical testing are deferred at the user's request and do not block the Test Mode milestones.

## Scope

- One separate titled, movable, resizable, minimizable Test Output window with a plain black content view.
- Open Output / Close Output actions in the editor and Window menu.
- Open is available only for Test Window; real-display discovery remains available but projector output is explicitly deferred.
- Default window content size 640 × 360 points, minimum 320 × 180 points. Fixed simulated target remains 1280 × 720; resizing the window does not alter it.
- Repeated Open Output brings the same window forward and restores it if minimized; no duplicates.
- Native window close and Close Output update shared status immediately and preserve project/editor state.
- Launch never opens output automatically. New Project preserves the open test window. Successful editor close closes test output; canceled close leaves both intact. Quit closes both windows.
- Changing to a real-display destination closes Test Output, without starting external output.
- No renderer, resolution picker, persistent window geometry, or Show Output shortcut in this slice. Resolution/aspect fitting is v1.03.2; window persistence/navigation polish is v1.03.3; Metal is v1.04.
