# v1.12.2 — Face masks and cutout verification

October 7, 2026. Implemented and automatically verified locally. Routine visual acceptance remains pending with the user. This slice does not complete the full v1.12 milestone.

## Delivered behavior

- Face-owned hard polygon boundary and up to seven polygon holes, each with 3–32 points for valid rendering. Both windings and concave polygons are supported. Holes must remain strictly inside the boundary and cannot overlap, touch or nest.
- Create/enable/disable/remove masks in the face inspector. Draw boundary/hole points by clicking the projected editor or the 160×160 local inspector square, then Finish/Cancel. Drawing is runtime-only until Finish; invalid creation retains the draft and explains the error. Select/drag existing handles, split the selected edge with Add Point, delete points down to three, or edit X/Y coordinates. Document/face/object selection changes cancel draft drawing. Local editing remains available for invalid output corners.
- Bounded semantic-invalid edits are saveable/recoverable. Enabled invalid masks suppress their face and report the repair needed; disabling retains the draft while rendering the full face. Nonfinite/out-of-range coordinates, excessive ring/point counts and duplicate ring IDs within one face are rejected by persistence.
- Clip original face UV before every content and calibration branch. Removed fragments reveal the next valid surface or the black background. Output corner movement carries the mask; input maps, crop/flips and shared content do not move it. Opacity, brightness, master fade/blackout and calibration priorities retain their existing behavior.
- Masks remain independent between object faces. Group/attach/detach, source/preset/look edits, geometry locks and existing reset scopes preserve masks. Duplicates copy shapes with independent polygon identities. Only explicit mask operations remove the mask. Handles and draft paths remain editor-only.
- Format 6 saves masks and migrates formats 1–5 without masks. Dirty state, successful/failed save baselines and recovery include masked and bounded invalid drafts. New saves require this local preview or a newer app; earlier app copies cannot open format 6 packages. Preserve older saved packages when comparing older builds.
- Metal uploads cached bounded payloads when scenes change: eight uint2 descriptors and at most 256 float2 vertices. No per-frame polygon validation or buffer allocation. Hard edges only; feathering, named regions, mesh warps and undo/redo remain future work.
