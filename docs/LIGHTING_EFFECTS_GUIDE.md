# Reusable lighting effects

Open Projection Mapper build 35 from Applications and choose Lighting. Use a project copy for rehearsal if you also need to open it in build 34. Build 35 writes project format 16 and opens earlier formats.

1. Select a fixture group, set the playhead, and open **Lighting Effects** above the timeline. The selected fixtures populate the draft. Use **Use Fixture Group** to replace that target list.
2. Give the effect a name and pick Forward, Reverse, Bounce or Wave. Set the step time, repeats and colors. For a chase, use the up arrows to set fixture order. For a wave, choose a direction. The draft captures fixture positions when you select a group. Use **Refresh Wave Positions** to pick up any subsequent placement changes.
3. Click **Save Preset**, then **Save Clip** to place it on the timeline. Presets are stored in the current project. A matching name offers **Update Preset**.
4. Move the playhead, select another group and open **Lighting Effects** again. Use **Load Preset** and **Save Clip**. Click either clip on the timeline to edit it independently. Updating or removing a preset leaves existing clips as authored. Command-Z undoes library and clip edits.
5. Resume fixtures and play, scrub or loop. The colored rings identify fixtures driven by the active effect step and reflect the simulated output. Hover over a fixture for its effect and output state. Check switched plugs on/off, RGB strip colors and a moving head with position keys and the Path chart enabled.
6. Save and reopen the show. Check that both placements retain their individual settings and the preset is available for a third placement.

Existing fixture cue priority, manual overrides and blackout apply to effects and their highlights. Test Window and simulated fixtures are the rehearsal setup. Use normal output controls to enable Test Window.
