## Presets and reset

Project-owned generator presets have stable IDs, unique bounded names (80 characters), typed content, literal colors and validated settings; maximum 100 presets. Save New, Apply, Update and Delete are in the source inspector. Applying copies settings into the selected standalone source or shared object owner, preserving source identity, geometry, membership, tags, input maps, visibility and runtime phase. Deleting a preset does not change already-applied content. Reset Effect Settings restores default generator parameters and both colors while preserving the selected effect, layout and playback.

Presets are in-memory project data and participate in dirty/discard protection. Persistence is v1.10. Preset/source IDs provide stable future save identity; the v1.11 palette extension should attach color bindings to explicit color slots with literal fallback rather than replacing layout or deriving references from names. No unused palette runtime or save engine was added now.

## Time and owner scope

- Global seek accepts finite 0–3600 seconds, preserving playing/paused state and speed. Inspector numeric Seek and a first-minute scrub slider use the same API; live elapsed-time readout updates during playback. Invalid input is rejected.
- Effects evaluate explicit time, seed and owner settings without simulation catch-up. Temporal loops are analytic at 8/effect-rate seconds at global 1×. Same-time requests reproduce frames after forward/backward seeks and loop crossings.
- Owner Pause/Resume/Restart affects one standalone source or all members of a shared object. Global Play/Pause controls progression of the timeline; global Restart resets every owner phase while preserving owner-local pause states.
- A paused owner holds its local time while the timeline advances. Resume preserves that phase using a runtime offset. Global seek shifts frozen owner times by its delta; seeks before a local restart origin clamp local time to zero until timeline catches up.
- Duplicate/detach/ungroup inherit the source's runtime clock state. Grouping copies the frontmost member's state; attaching adopts destination playback. Cleanup removes runtime entries for deleted/unreferenced owners, and New Project clears them.
- Clock state, pause/restart and seeking remain separate from project data/timestamps/dirty protection. Applying/resetting/updating presets is a project edit. Views draw continuously only if a valid visible unpaused animated source needs it; static/paused/unavailable views remain on demand/suspended.

Separate Release opt-in workload completed successfully with Metal validation disabled. Evidence: Performance.log and performance/mixed-effects.json. Both workloads submit two serial offscreen views, at exact preset resolution, four warmup pairs then 20 measured pairs per preset. Mixed workload has six adjacent faces using all six effects. Heavy workload has eight full-canvas overlapping particle faces per view with density 16 (256 particles per owner).

Performance depends on covered pixels/overdraw, not only bounded particle count.
