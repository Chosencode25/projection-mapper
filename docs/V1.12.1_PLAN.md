## Result and scope

Choose Grid, Checkerboard, Crosshair, White or Black to inspect the mapped shapes, then return to Normal Content. One project-wide mode controls both the editor preview and clean Test Window. It covers every currently visible, valid mapped face in the existing draw order; it does not illuminate the unmapped background. Hidden faces/objects stay hidden, invalid geometry stays suppressed, and an empty project renders black with a useful calibration status.

This is a temporary display override, distinct from assigning Diagnostic Grid as a face's saved content. It does not replace sources, looks or palettes. Calibration uses opaque pattern pixels and bypasses content opacity, face/object brightness, crop and flips so a dim or transparent mapped face can be inspected. Saved master brightness, runtime fades and immediate blackout still apply. Geometry locks remain effective.

## Step 1 — Runtime state and lifecycle

Add an Equatable/Sendable calibration snapshot with pattern Normal by default, 8 columns, 8 rows and a 1-pixel line width. Validate counts in 2–64 and line width in 1–4 drawable pixels; reject invalid/nonfinite edits without changing state. No pattern animation, colors, movable crosshair or imported test images are needed.

The session owns the state and carries it to both renderer snapshots. Pattern/settings changes never modify the project, timestamps, saved baseline or recovery files. Schema remains 5; do not save calibration preferences in a project or UserDefaults.

Successful New/Open/recovery resets calibration and its settings to defaults. Cancelled/failed file actions retain them. Save/Save As leave calibration active without writing it. Output close/reopen retains the session's current mode/settings. Library/content edits while calibrating change their normal persistent values; exiting shows the current project rather than restoring an obsolete content copy.

## Step 2 — Coordinates and patterns

| Pattern | Coordinates | Appearance |
| --- | --- | --- |
| Grid | Effective input map into each owner's canvas | White cell boundaries on black; adjustable rows/columns and line width |
| Checkerboard | Same owner-canvas coordinates | Alternating opaque black/white cells; adjustable rows/columns |
| Crosshair | Original face-local UV | White center axes and border on black; adjustable line width |
| White | Each mapped face | Opaque white before master attenuation |
| Black | Each mapped face | Opaque black; explicitly identified as a test pattern |

Grid/checker preserve Continuous member regions, orientation/mirroring and Repeat's full-canvas mapping. Standalone custom input regions are also honored. Bypass content crop/flip only; never rewrite input maps or object mode. Linked equal coordinates therefore sample matching grid/checker values. Separate owners use their own normalized canvas; there is no automatic 3D reconstruction.

Crosshair marks each face's center and boundary independently, making its purpose distinct from the owner-canvas patterns. Use analytic Metal patterns with derivative-based edge antialiasing so line width follows drawable pixels across warped shapes, resolution presets and resize. No project-owned bitmap asset or dependency is needed.

## Step 3 — Render priority and clocks

Prepare calibration appearance defaults in render data only; preserve the original project values. Keep one shared render path for both views. Retain background black, existing geometry/input validation, and ordered compositing. Add a dedicated runtime calibration parameter rather than new saved SurfaceContent cases.

The rendering order is geometry/validity and future face-local mask clipping → calibration or normal content → compositing → master brightness × fade gain. Immediate blackout forces black with highest priority. In 1.12.2, mask testing must precede every pattern branch, including White/Black; holes may reveal another legitimate overlapping face. This slice must leave a clear insertion point for that clipping.

Entering/exiting/changing calibration never changes generator play/pause, source clocks, seed, speed or seek position. Generators continue logically when playing and remain frozen when paused. Static calibration suppresses generator-driven frame scheduling; active fades still draw through their final frame. Black test, blackout and zero master brightness can idle because their visible output is black even while clocks advance. Hidden/closed views remain idle and evaluate elapsed state when restored.

Exiting Calibration changes only the pattern mode. Restore continues to release blackout/fade toward saved master brightness while retaining the selected calibration pattern. Restore cannot make the Black test pattern white. Selecting another pattern cannot clear blackout; show both active states clearly.

## Step 4 — Controls and status

Add project-level Calibration controls to the inspector: pattern picker, rows/columns for Grid/Checkerboard, line width for Grid/Crosshair and a reachable Normal Content action. Explain the temporary appearance bypass and master-control priority in a short caption. Keep count/line-width controls hidden for patterns that do not use them.

Add a compact toolbar calibration menu and a Show menu submenu. Proposed Control-Command-C toggles Grid/Normal, with an explicitly named Exit Calibration action available when active. Verify conflicts/native routing before retaining the shortcut; do not intercept unmodified letters, Space or normal text-field arrows. Existing blackout/restore shortcuts remain intact.

Display the active pattern and visible mapped-face count. Identify Black test separately from latched blackout, faded output, zero master brightness and renderer failure. Keep status/labels/handles in the editor UI only; clean output contains no text or selection decorations. Do not add automatic brightness changes when entering calibration.
