# v1.11.3 — Reusable show controls

October 6, 2026. Implements the [detailed plan](V1.11.3_PLAN.md) and completes the three-slice v1.11 Surface Controls milestone. Required Xcode 27.0 beta 5 (27A5237l) reverified; deployment target remains macOS 15.0. Routine visuals belong to the user; no screen control was used.

## Implemented behavior

- Project-owned named looks capture supported content, generator parameters/colors and appearance using stable object/face IDs. Save/apply/update/rename/delete are available in the inspector. Shared content is captured once per object; face entries recall overrides or inheritance. Apply validates before one transaction, skips/reports deleted or regrouped targets, and preserves corners, input maps, links, membership/mode, visibility, names/tags/order, locks, source IDs, playback and master output controls. Newly added targets stay untouched.
- Project-owned palettes have stable named slots, RGBA colors, rename/reorder and explicit primary/secondary color bindings on standalone/shared owners. Direct color edits unlink the affected channel; detach/duplicates retain palette bindings. Generator presets capture resolved literal colors; preset application/reset clears affected bindings.
- Removing a slot or palette reports reference counts and materializes current colors in live content, dormant face sources and saved looks before removing references. Cancellation leaves state unchanged. Palette-bound looks follow current slot values; literal colors remain snapshots.
- Saved master brightness 0–100% attenuates RGB after face-brightness clipping without changing alpha or source colors. Saved fade duration accepts 0–30 seconds (default one). Runtime linear fades use a shared monotonic clock independent of generator play/pause/seek/speed. Reversal starts at current gain; repeating a target does not restart the fade; zero duration is immediate.
- Immediate Blackout latches, cancels a fade and holds output black. Restore clears the latch and fades from black toward saved master brightness. Looks/brightness edits cannot clear blackout. Toolbar actions remain reachable with the inspector hidden; Show menu shortcuts are Command-Shift-B and Command-Shift-R. Editor controls remain visible while rendered content is black.
- Shared editor/Test Window snapshots and fade-aware rendering demand support static or paused content and settle after the final frame. Hidden/closed views do not drive rendering; output reopening evaluates current gain. Blackout/fades never dirty the project or create recovery writes. Saving preserves runtime state; New/Open/recovery reset fades/blackout and load saved brightness, with generator playback paused.
- Schema 5 saves/recovery include looks, palettes, bindings and master configuration. Schemas 1–4 migrate with defaults while retaining prior data. Validate bounded finite values, payload shape, library limits and live/stored references; stale look target IDs remain legal. Reject oversized manifests on encoding and decoding; failed validation/save preserves prior state and the last good package.
