## Implemented behavior

- `MappingProject` owns exactly one `MappingSurface`, containing a stable UUID, name, four normalized corners and fill. Fresh projects create Surface 1 with corners (0.25, 0.25), (0.75, 0.25), (0.75, 0.75), (0.25, 0.75), clockwise from the top left. Coordinates have a top-left origin and describe the fitted output, excluding margins.
- The session derives its immutable drawing snapshot from that surface. Both independently owned renderers receive it. Existing preview/output views update their snapshot after reset; future reopened output uses the new scene too. Scene updates preserve drawing suspension and asynchronous on-demand rendering.
- Surface 1 starts selected. Sidebar selection and Deselect Surface control only inspection state. Invalid/stale IDs cannot select a nonexistent surface. Selection does not change project timestamps, geometry, scene or dirty state.
- The scrollable inspector shows one surface, selected name and read-only normalized corner pairs, or no-selection guidance. Selection indicators stay in the editor sidebar; clean output contains only the rendered surface on black.
- Reset creates new project/surface identities, selects the new default surface and clears changes. Output stays open, resolution/output preferences and panel state remain independent. Nondefault injected surface name/corners/fill activate existing discard protection; default surface creation does not.
