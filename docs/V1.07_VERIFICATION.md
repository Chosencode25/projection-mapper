## Implemented behavior

- A generated 512×512, 8×8 checkerboard with orange grid, cyan border and orientation markers (red TL, green TR, blue BR, yellow BL). Ten CPU-filtered mip levels are uploaded once per renderer. Linear texture/mip sampling supports downscaling; no per-frame texture creation/upload or file import.
- New projects default to Diagnostic grid; the inspector can select Solid fill. Content choice is project data, activates discard protection and updates existing/future output and preview snapshots. Reset restores default grid and corners; output preferences are independent.
- Double-precision homography maps a unit square to the normalized quadrilateral. Metal applies its normalized inverse to interpolated surface positions and divides homogeneous coordinates per fragment. One transform spans both triangles, avoiding a diagonal UV seam.
- Require finite 0…1 corners, consistent strictly convex winding (either winding supported), absolute consecutive-edge cross products above 0.000001, invertibility, and positive safe projective denominators. Crossed, concave, collapsed, excessively thin or unsafe shapes encode only the black clear. Recovery resumes normal rendering without recreating the view.
- Warning text is editor-only, including when inspector is hidden or surface deselected. Its fixed 32-point slot prevents valid/invalid transitions from moving the fitted preview during dragging. Handles remain editable. Inspector Edit corner selector and priority for the active handle allow recovering overlapping corners. Output has no handles, outline or warnings.
- Existing on-demand, asynchronous command submission, suspension/resume and lifecycle ownership remain in place. The homography is refreshed with the scene; texture resources persist with the renderer.
