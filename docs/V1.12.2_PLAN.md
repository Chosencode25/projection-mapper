# v1.12.2 — Face masks and polygon holes

Implement locally after calibration; retain bundle 1.11/build 8 until the complete 1.12 milestone. No Git delivery or release for this slice. Exact Xcode: 27.0 beta 5 (27A5237l).

1. Add face-owned, normalized original-UV polygon masks: one outer boundary and up to seven holes, at most 32 points per ring. Support concave polygons and either winding. Reject nonfinite/out-of-range points and resource excess. Diagnose degenerate/self-intersecting polygons, holes outside/touching the boundary, and overlapping/touching/nested holes. Bounded semantic-invalid drafts remain saveable and repairable; enabled invalid masks suppress the face, disabled masks retain their draft without clipping.
2. Clip in the shared Metal renderer before solid, animated, diagnostic, and calibration branches. Cutouts reveal the next legitimate surface, or the black background. Input regions, crop, flip, appearance, source playback, joins, fade and blackout retain existing behavior. Mask coordinates follow output corners without following source sampling.
3. Provide inspector and editor controls: create full-face boundary, enable/disable/remove, choose boundary/hole, draw a new polygon with clicks and Finish/Cancel, drag handles, insert an edge midpoint, delete a point, and edit normalized coordinates. Draft drawing stays runtime-only until Finish. Selection changes and document replacement cancel it. Geometry locks protect output corners but allow mask edits. Handles stay in the editor. Keep a face-local inspector editor available when output corners are invalid.
4. Add format 6 migration from formats 1–5 with no masks. Include masks in dirty/save/recovery state. Duplicate masks independently; retain them when grouping, detaching, applying looks/presets, or resetting existing face/object controls. Remove masks only through explicit mask operations.
5. Verify model validation, actual offscreen GPU clipping and layering for all patterns/content, transforms, session preservation, older-format migration, package/recovery round trips and failure safety. Run full Debug and Release checks using required Xcode; deliver a verified universal Release app to app/ProjectionMapper.app, preserving the previous app in builds/v1.12.2/. Routine visual acceptance remains with the user. Update progress and verification notes.

Hard edges only. Feathering, meshes, labels/outline options and undo/redo remain in their later roadmap slices.
