## Delivered behavior

Plasma, animated value noise and particles join the existing gradient/lines/checkers, grid and solid content. Procedural effects evaluate explicit shared elapsed time and retain perspective/input maps. Object faces share one settings owner and global clock; Continuous samples a shared canvas, Repeat samples the whole pattern. Duplicate/detach preserve the established independent/shared owner rules. Content and parameter changes preserve geometry, input maps, draw order and runtime transport.

| Control | Applicable content | Bounds |
|---|---|---|
| Two colors | All animated effects | Finite RGBA components 0–1; UI colors opaque |
| Effect speed multiplier | All animated effects | 0.25–4, applied to global playback time |
| Scale / line spacing | Gradient, lines, checkers, plasma, noise | 0.5–4 |
| Direction/orientation | All except noise | Eight directions at 45-degree increments |
| Contrast | Plasma/noise | 0.1–1 |
| Particle count | Particles | 4–16 cells per axis, giving 16–256 particles |
| Particle size | Particles | Radius 0.04–0.35 of a cell |
| Seed | Noise/particles | Integer 0–999999 |

Only relevant controls appear. Invalid/nonfinite settings are rejected. Real owner edits dirty the project; no-op/rejected edits do not. Effect speed is an owner parameter and can change the sampled phase when edited; global transport speed changes preserve the current phase. The analytic effects repeat every 8/effect-speed seconds at global 1×. Direction rotates the simple pattern coordinates; particles travel on a wrapped canvas using integer horizontal/vertical/diagonal displacement, preserving loop continuity.

Noise uses seeded integer hashing with smooth bilinear value interpolation and a periodic time offset. Particles place one seeded point in each shared-canvas cell, with analytic wrapped motion. Each pixel examines only nine neighboring cells; increasing particle count does not introduce a loop over all particles or CPU simulation. No per-frame generated texture, particle array, random-state mutation or extra content-owner GPU resource is required. Paused/static/unavailable view scheduling remains unchanged.
