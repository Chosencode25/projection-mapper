## Video coverage

Thirteen serialized video tests generate their own media through AVAssetWriter/AVFoundation. They cover:

- Actual H.264/HEVC, rotated and audio-bearing files; poster/raw-byte preservation; malformed file and symlink rejection.
- Format 8 migration, source ranges, leading/trailing trim versus move, looping phase, rates and invalid bounds. Mute/placement edits preserve a shortened block's duration; source-speed edits preserve its footage.
- Deterministic stale/cancelled imports after New; cleanup without replacing changed mapping.
- Adjacent clips using the same asset at different in-points; backward/rapid seeks; active clip identity and dark gaps.
- One request/player/frame per shared owner; zero-opacity members do not block visible siblings. Real AVPlayer mute/rate/volume/device commands are checked with master volume zero, including unsupported-rate muting, pause, rearm and simulated selected-device loss when an output device is enumerated.
- Offscreen Metal colors/orientation; shared Continuous/Repeat, crop and mask behavior; outgoing clip-frame rejection.
- Hidden-view, calibration and full-dark visual resource suspension, followed by current-time frame restoration. Deliberate audio remains independent of visual blackout.
- Portable moved packages, timeline-only videos, saved look/reference retention, recovery, failed/cancelled writes, shorter relink rejection, owner duplicate/detach/delete and paused/muted reopen.
- Runtime source speeds 0.25×, 0.5×, 1×, 2× and 4× against the shared clock; repeated loops with one shared object versus three independent owners. Throughput sampling waits for the decoder's first frame; loading latency is distinct from steady playback.

## Findings and corrections

Paused AVPlayerItemVideoOutput could return a previous decoded frame after a completed seek. Paused requests now use AVAssetImageGenerator with stale-generation guards; running output validates frame timestamps both when requested and when published, and expires stale held frames. Decoder/color conversion is lossy: pixel assertions check dominant colors and source timestamps rather than exact RGB values.

Video ownership is included in video-scene equality while procedural scenes retain their existing visual equality semantics. Large portable/recovery copies now use chunked cancellable video I/O off the main actor. Actual media is inspected before native Open/recovery replacement and manual saving. Invalid/non-finite track dimensions are rejected before integer conversion. Clip-only missing media can be relinked from the selected block.
