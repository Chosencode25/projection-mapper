# v2.16 Winter Lights Encore rehearsal

This procedure uses the project-owned 24-second Encore demo from assets/demos. Start with a disposable copy. Use the Test Window and simulated fixtures for the checks below. Record the build, Mac, macOS version, browser or player, and whether physical hardware was present.

## Run and inspect the show

1. Open the disposable show. Set Test Window resolution to 1920 × 1080. In **Show**, open the output, run **Check Readiness**, and click **Prepare & Arm**. Expect the show to remain paused until you press **Play**.
2. Watch and listen for the following checkpoints. Scrub in Edit if you want to inspect a single frame.

   | Show time | Check |
   | --- | --- |
   | 4.75–8 s | The greeting spans the three linked faces as snowfall and sparkles play. |
   | 4–16 s | The Video Window has an independent outline. The outline and video have a transition near 12 s. |
   | 12–16 s | The ornament animates its mouth as the lantern's diamond cutout remains visible. |
   | 16.75–20.5 s | The countdown points to the 20-second Finale and holds zero briefly. |
   | 24 s | Projection goes dark and fixtures stop at the end of the song. |

3. Repeat on a second disposable copy. In Edit, pair an Editor phone, move **Snowfall Greeting** from 4.75 to 5 s, and retime **Finale Gold** from 20 to 20.25 s. Verify both changes in the Mac timeline, undo both, redo them, save, and reopen. Switch to Show and check that timeline edits are locked. Revoke the phone from the Mac and confirm access ends.
4. While the show is running, close Test Output. It should pause and darken. Reopen output, arm again, restore blackout as needed, and press Play to resume. Repeat with a simulated controller failure on a disposable copy. Remove a video from a third disposable copy and verify readiness names it before enabling playback. Keep the original demo package intact.
5. Make a two-item playlist from two disposable saved shows. Set both to the full song duration. Check that the second starts after the first ends and that the final item leaves output dark. If testing a schedule, use a time you can supervise and disarm it after checking the cutoff.

## Inspect delivered files

Choose **File → Export Video**. Export **Mapped Projector Output** at 1920 × 1080, 30 fps, from 0 to 24 seconds with **Include project song** on. You should be able to open the 720-frame MP4 in a compatible player. Watch the same checkpoints and listen for sync. Export the panorama with **Unmapped Content Canvas** and audio off. The canvas should occupy the full frame.

Choose **File → Collect Show Assets**. Move the whole .projectionmap package to a different folder, put the disposable original aside, and open the moved copy. Confirm the song, video, image, links and cue timing are present.

## Automated coverage

Run with Xcode 27.0 beta 5 (27A5237l). For the shorter regression, select the EncoreAcceptanceTests suite. Set TEST_RUNNER_PROJECTION_ENCORE_ACCEPTANCE to a fresh existing output directory to enable the full exports and playlist tests. For the 30-minute run, select EncoreSoakTests and set TEST_RUNNER_PROJECTION_ENCORE_SOAK_REPORT to a new writable JSON file. TEST_RUNNER_PROJECTION_ENCORE_SOAK_SECONDS defaults to 1800. Disable Metal validation for timing runs with TEST_RUNNER_MTL_DEBUG_LAYER=0 and TEST_RUNNER_MTL_SHADER_VALIDATION=0. Run the measured soak on its own.

The soak uses the show's real AVPlayer soundtrack clock with its output muted, a full-size offscreen Metal texture, and a Test Window created without presenting it. It samples at a target of 30 fps, records clocks and resource use, and checks output and media teardown. Decoder availability is counted per required video frame at the moment of submission. Clock versus wall time includes seeking across repeated song wraps. Interactive window behavior, audible playback, phone browser gestures and optical timing are user acceptance checks.

When the equipment is available, repeat on the physical projector, moving head, Arduino and each intended audio route. Record any independent timing measurement, network reconnection, and setup differences in the compatibility record.

## Build 44 cue recording and layout rehearsal

Open the saved **Encore on Second Layout** rehearsal project with build 44. In **Show**, select **Test Window**, click **Prepare & Arm**, and press **Play**. Listen for uninterrupted playback and watch the Upstairs Window turn cyan from 4.90 to 6.40 seconds. The simulated Upstairs Plug switches on near 5.07 seconds and off near 5.50 seconds. To inspect the fixture transitions individually, scrub across those times in Lighting.

The automated rehearsal used the actual soundtrack clock with audio muted, rendered an offscreen frame during the cyan clip, and observed both fixture transitions after reopening the remapped show. The two rehearsal projects and measured times are under `builds/whole-show-layouts/rehearsal/`. Visual and listening acceptance remain pending.
