# Movement paths rehearsal — build 34

Open the local `builds/lighting-paths/ProjectionMapper.app`. Applications still contains build 32. Use a copy or a new Playground show for rehearsal: build 34 saves **project format 15**, which requires build 34 or newer. Original format-14 projects remain supported for opening.

1. Open **Lighting**, select a moving head or a named group containing heads, and click **Resume Fixtures**. Use the existing setup panel for patches. Brightness/color cues remain independent of position keys.
2. Set the song playhead to the first time (for example 0 seconds). Audition Pan/Tilt in the fixture/group controls and click **Capture Position at Playhead**. The chart's plus button and each moving head's Positions-row plus button also capture a key. Group capture writes one key per head in a single undo step; it then selects the first captured key.
3. Select the fixture/group again, move to another time (for example 4 seconds), set another Pan/Tilt position, and capture again. Reselect the group for each additional group capture. Capture at an existing key time updates that key rather than making a duplicate.
4. The schematic's **Path** toggle shows a pan/tilt chart for the selected head (first head of a selected group). Cyan diamonds are keys, lines show travel in pan/tilt coordinates, dashed lines indicate Snap, and the orange ring shows the current intended position. This chart is an authoring guide, not a measured beam path across the house.
5. Select the destination key and choose **Arrive using → Linear** or **Ease In/Out**. Its curve controls travel from the preceding key. **Snap** holds the preceding position until the destination's exact time. Before the first key, normal cue positions apply; the last key holds afterward.
6. Drag a diamond in the chart to change its position. Drag a cyan Positions-lane diamond horizontally to change time, using the shared Snap setting. Double-click a Positions lane to capture at that time. Exact time, pan and tilt fields are in the key inspector. Duplicate/Delete (including keyboard commands) target the selected key; Escape deselects Lighting without changing the projection selection. Command-Z undoes a completed drag or group capture.
7. Use **Release Manual Override** if shown. For an active manual GO, open Cue List and use **Release to Timeline**. Manual audition takes priority over authored motion until released. Then play, pause, seek backward/forward and rehearse a song loop. With dimmer at zero, the chart and schematic aim guide still show the intended movement; add normal brightness/color cues to see a lit beam preview.
8. Verify that brightness/color cues keep their settings, other fixtures stay unchanged, Edit/Lighting/Show share the same playhead, and saved/reopened keys retain positions, timing and curves. A fixture can have only one position key at a time; invalid or colliding edits retain the previous valid programming and report a message.

User visual/listening acceptance is pending. Please check chart motion during playback, pointer dragging and inspector fields at your normal/minimum window sizes, and a short Test Mode/simulated-fixture loop. No screen control or app launch was used for this build. Physical moving-head/projector timing remains deferred.
