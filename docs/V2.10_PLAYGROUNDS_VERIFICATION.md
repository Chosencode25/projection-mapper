- Independent local playground packages, schema 1, using portable project format 14. Library rename/note, duplicate, deliberate confirmed update, import and export. - New shows are independently named, UUID-identified autosaved drafts written before switching. Loading resets output, song clock, undo/history, selections and manual lighting state; audio overrides reset and the phone remote stops. Base targets start black; overlays/regions transparent; fixtures remain dark. New shows use Edit until the separate Lighting workspace is implemented.

Failed extraction or draft writes keep the original open; failed library replacement keeps the saved playground intact. Cancelling song selection leaves a usable blank draft; a failed soundtrack import reports through the existing song importer so another song can be selected.
