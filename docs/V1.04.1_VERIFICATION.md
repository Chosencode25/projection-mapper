# v1.04.1 — Metal Foundation Verification

Verified locally October 5, 2026. Toolchain: `/Applications/Xcode-beta.app`, Xcode 27.0 beta 5, build **27A5237l** (rechecked before implementation). Apple Silicon Debug build on the development Mac running macOS 27.0; macOS 15.0 remains the deployment target.

## Implemented

`MetalRenderer` owns the Metal device and command queue independently of the window coordinator. A fitted `MTKView` draws a fixed blue diagnostic clear on demand; the outer view remains black. The view retains its renderer because MTKView's delegate is weak. Missing/zero-size drawables are skipped safely. No shader pipeline, rectangle, mapping surface, or editor renderer is included in this slice.

Metal device or command-queue initialization failure replaces the rendering view with a readable error message in output. Close/reopen retries initialization. The simulated resolution remains separate from actual drawable dimensions; this is not evidence of full-resolution 4K rendering or measured frame pacing.

## Automated evidence

- All **38 tests** passed (35 existing regressions plus 3 Metal checks).
- GPU clear: create a real render-target texture, encode/commit the shared clear operation, wait for successful GPU completion, and read BGRA pixels from opposite corners. Actual bytes match the diagnostic color.
- Injected missing device and queue: verify error text, visible label, absent Metal view, and fitted failure layout.
- Native NSWindow/MTKView integration: all five presets, wide/tall content sizes, correct fitted frame, non-nil drawable, close/reopen. Existing regressions cover window preferences/recovery, project independence, output selection, and navigation/window ownership.
- Test evidence: `builds/v1.04.1/test-verified.log` and `Tests-verified.xcresult` (excluded from Git). Initial sandboxed attempt failed because Swift macro plugins could not run; rerunning with the same pinned toolchain outside the sandbox succeeded.

## Running app and delivery

- Launch starts with output closed and the existing 4K preference restored.
- Show Output displays the blue Metal clear with black margins.
- Live Portrait selection changes the fitted surface and output title without recreating the window; visible portrait content has black side margins.
- Native close preserves the editor; Control–Command–O reopens output, and Control–Command–E returns to the editor.
- Native minimize followed by Show Output restores visible drawing.
- Original 4K preference restored and output closed after checks. Native resizing is covered by actual NSWindow size changes in the tests; pointer-driven resizing was not used for acceptance.
- Tested app copied to `builds/v1.04.1/ProjectionMapper.app`; `codesign --verify --deep --strict` passed. Bundle remains v1.03.1/build 3; no tag, archive, or release.
