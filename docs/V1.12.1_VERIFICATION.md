## Implemented behavior

- Session-only Normal Content, Grid, Checkerboard, Crosshair, White Test and Black Test modes. One snapshot controls preview and Test Window. Patterns cover visible valid mapped faces in existing draw order; hidden objects/faces remain hidden, invalid geometry is suppressed and unmapped background stays black.
- Grid/checker use the effective input map into the owner's canvas, preserving Continuous/Repeat, rotation/mirroring and custom regions. Crosshair uses original face-local coordinates for center axes/border. Opaque analytic black/white patterns bypass source opacity, face/object brightness, crop and flips in render copies only. Normal saved Diagnostic Grid content remains unchanged.
- Defaults: Normal Content, eight rows/columns and one-pixel line width. Bounded rows/columns 2–64 and line width 1–4 drawable pixels; invalid edits preserve state. Derivative-based edges support resize and warped geometry. Controls only appear when used by the selected pattern.
- Calibration never rewrites project content/layout, source IDs, looks/palettes, geometry locks, clock anchors or saved settings. It never dirties the project or writes recovery. Content edits made while calibrating appear upon exit at the current logical phase.
- Existing saved master brightness and runtime fades apply; immediate blackout wins. Restore releases blackout/fades brightness while retaining calibration. Black Test stays black after Restore; exiting calibration does not clear blackout. Status identifies pattern, mapped-face count, empty/invalid layouts and output overrides.
- Static calibration suppresses generator-driven rendering while logical playback keeps its normal play/pause/seek behavior. Active fades draw through their final frame; Black Test, blackout and zero master brightness can idle. Hidden/closed views do not drive drawing; reopening evaluates elapsed state.
- Inspector and compact toolbar/menu controls expose patterns and Normal Content. Control-Command-C toggles Grid/Normal; existing blackout/restore shortcuts remain. Editor UI/handles remain separate from clean output. Renderer initialization errors remain reported by the existing preview/output fallback.
- Save/Save As retain runtime calibration without writing it. Successful New/Open/recovery resets calibration/settings; failed operations preserve them. Schema remains 5, with no new persistent fields or migration.
- Mask clipping insertion point is documented ahead of calibration/solid shader branches. Masks are NOT implemented here; 1.12.2 will add them and corresponding clipping tests.
