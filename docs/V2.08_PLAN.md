# v2.08 — Holiday Choreography

Planning draft, November 11, 2026. Build on the v2.07 source, the v2.05 song clock, and the v2.06 timeline, markers and fixture groups. Rehearse with Test Mode and simulated fixtures while native hardware work is deferred.

**Rehearsal goal.** Run a short chorus with snowfall across a linked three-face object, a color chase across separate props, and a projection crossfade on a marked downbeat. Scrub into the middle of the transition, then loop the chorus and confirm it repeats the same way.

## 1. Add holiday presets to Edit

- Add snowfall, twinkle, candy-cane stripes, stars, icicles and ornaments to the existing effect and preset picker. Reuse the current generators wherever their output fits and add render code for shapes or motion the current generators cannot express.
- Expose the palette, speed, scale, intensity and density settings relevant to each preset. Keep preset seeds stable so scrubbing and looping reproduce the pattern. A preset should work on a single face or a linked object and retain the target's mapping, masks and clip timing.
- Bound the number of generated elements and reuse existing rendering resources. Verify at least one still frame and a repeatable moving sequence for every preset.

## 2. Author chases and waves on the timeline

- Add a choreography section in Edit to choose and order projection owners or fixtures, select a look or palette, and set the step interval, repeats and direction. Support forward, reverse and bounce. Each linked projection object counts as one target. Save ordered target IDs so renaming a fixture or face leaves the sequence intact.
- Add a 2D wave view with user-authored positions and a direction. Compute the delay from each target's position along the direction. The diagram describes the show layout. Its spacing is set by the user and need not match projector coordinates or physical distance.
- Use timed choreography clips on the existing song ruler. Trim or move a clip as a single undoable edit and preview its targets in Test Mode or the fixture preview. Show missing targets and disable their contribution. At a clip boundary, the existing timeline resumes control for targets the choreography clip no longer owns.
- Evaluate the pattern from the current playhead so seek and loop rebuild the correct step. Direct fixture overrides and manual GO keep their current priority over timed cues. Resolve overlaps between choreography clips and regular cues explicitly. For the first version, reject overlapping choreography clips on the same target and give a regular fixture cue priority at its timestamp until the next choreography step. Projection overlaps use the explicit crossfade rule in the next step.

## 3. Crossfade projection and palette looks

- Add a transition duration and easing to adjacent projection clips on the same content owner. Blend the outgoing and incoming visuals over the authored interval, with at most two active sources per owner. Limit the transition to the available clip and media handles. Cut at zero duration. Keep ordinary overlapping clips subject to existing validation.
- Evaluate both sources from the same song time. Apply the owner's output geometry and mask to the result and preserve the continuous image across linked faces. Test Mode and Projector Mode share this rendering path.
- Fade between palette looks per target without changing the shared palette library. Report conflicts if two palette transitions would drive the same target at once. Keep switched plugs, binary RGB strip colors, and color and gobo wheels discrete. Retain the existing moving-head dimmer fade.
- Verify cuts, start/midpoint/end of a fade, media gaps, rapid seeks, loop wrap and the two-source render limit. Measure the extra decode and render cost on a short image/effect and video transition.

## 4. Trigger on beat or bar

- Extend the existing Beat markers with a downbeat flag. Let the user choose **Next Beat** or **Next Bar** for manual GO or a look change. Show the queued target and trigger time in Show and allow cancellation.
- Resolve the boundary using the authored markers and active loop. Show a clear message when the requested boundary is missing. Trigger once when the playhead crosses the boundary during playback. Clear a queued action on seek, Stop or project change. If a queue is set to the next valid boundary after a loop wrap, show that explicitly.
- Keep waveform beat suggestions editable and preserve hand-placed markers. Test exact boundaries, paused transport, canceled queues, repeated wraps and back-to-back manual triggers.

## Optional slice — Audio reaction

Prototype bounded modulation of intensity, scale or speed using a selected frequency band, gain and smoothing. Start with the imported song so rehearsal is repeatable. Live audio input is an explicit mode with a selected device, permission handling and a fallback if the input is lost. Verify the authored timeline separately from live input. Measure latency and CPU use before including live reaction in the verified milestone scope.

## Delivery and acceptance

- Propose portable format 13 for authored choreography, clip transitions and downbeat markers. Preserve old clips, fixture cues, seeds, palettes and mapping. Keep queued actions and live audio choices as runtime state. Use the existing validation, undo, recovery and save paths.
- During development, use focused tests. Before milestone delivery, run the full suite with Xcode 27.0 beta 5 (27A5237l). Add checks for chase order, authored wave coordinates, seed determinism, crossfade continuity, beat queues and save/reopen.
- Prepare a small chorus rehearsal with separate props and a continuous three-face effect. Play the chorus, jump to the fade midpoint, queue a look for the next bar, then repeat the loop and reopen the saved project. Record user visual/listening acceptance, measured workload and hardware checks in the verification notes.
