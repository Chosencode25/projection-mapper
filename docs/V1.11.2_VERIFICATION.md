# v1.11.2 — Locks, object movement and scoped resets

October 5, 2026. Local implementation on codex/v1.11-surface-controls. GitHub main remains the tested v1.10 source snapshot 55d242c; this intermediate slice has no commit/push/tag/release. Required Xcode 27.0 beta 5 (27A5237l) reverified. Bundle remains 1.10/build 7; deployment target macOS 15.0.

## Implemented behavior

- Persistent face and object output-geometry locks, reachable in sidebar and inspector. Object locking protects members without rewriting their own lock flags. Unlocking an object preserves individual face locks. Selection remains available; locked handles are gray. State APIs and native event handlers both enforce locks; a lock activated during dragging cancels that drag.
- Locks block output corner drag/nudge, output/full-face resets and deletion. Content/appearance, names/tags, visibility, draw order, explicit input maps/links/membership changes and duplication remain available. Detach bakes an effective object lock into the independent face; duplicates retain locks. This protects output geometry, not every project setting.
- Whole-object translation through a center square handle, focused arrows (0.1%, Shift 1%), inspector step arrows (0.1/1/5%) or numeric normalized X/Y offsets. All member corners receive the same bounded offset, with one modification timestamp and shared scene update. Clamp using the complete member bounding box; preserve relative geometry, IDs, content, input maps, membership, links and playback. Any locked member blocks the entire move. Text fields keep native keyboard focus.
- Scoped face resets for output corners, opacity/brightness, crop/flips, generator settings/colors and content defaults. Grouped faces require an override for face appearance resets; shared content resets belong to the object inspector.
- Full-face reset has a descriptive confirmation and resets unlocked output corners/visibility/appearance. Standalone content returns to diagnostic grid/default colors/settings with its original source ID. Grouped faces clear their appearance override while retaining shared content. Preserve face identity/name/tags/order, input map, membership, links, other faces and runtime clocks.
- Object resets for shared appearance/crop/generator/content. These preserve face overrides, membership, links and corners. Only the explicit confirmed input-layout reset arranges current member regions side by side with default orientation. It preserves link identities/directions/seams; custom joins may produce diagnostics afterwards.
- Schema 4 saves/recovery include lock flags. Schema 1–3 migrate with unlocked defaults, retaining existing appearance/layout/content/IDs. All new persistent edits participate in saved baselines/autosave. Loaded projects still start paused.
