## Automated coverage

Debug and Release each passed **317 correctness tests**, with zero failures and zero recorded runtime warnings on Apple Silicon macOS 27.2 (26B123). Four optional benchmarks were skipped, and the project's two legacy visible-window tests were excluded. Full results are under `builds/checks/`. Compact summaries are under `builds/v2.02/`.

- Patch validation covers CH 9 and CH 11 footprints, the last valid start address, controller compatibility, duplicate relay outputs and out-of-range assignments. Session tests verify that rejected edits retain the valid patch and that undo restores cue references.
- Lighting tests cover format 9 migration, round-trip persistence, exact cue and lead boundaries, backward seeks and a synthetic loop wrap. Pause, seek, timeline Stop, a new playback start and cue keyboard operations are exercised through the editor session.
- Simulation tests check relay values, duplicate-send suppression, manual override, blackout, Stop, fault isolation in each direction and unsupported profile status. DMX simulation operates on fixture values and reserved slots. Native DMX packet encoding is scheduled for v2.03 and Arduino serial output for v2.04.
- Verification uses the required Xcode 27.0 beta 5 (27A5237l). Xcode downloaded its matching Metal component. The deployment target remains macOS 15.0.
