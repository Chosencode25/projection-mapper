## Contract and implemented scope

Required Xcode 27.0 beta 5 (27A5237l) reverified and used via DEVELOPER_DIR. Code-only SwiftUI/AppKit. Bundle 1.15/build 12, portable schema 9 unchanged; existing schema 1–8 migrations retained. Test Mode is supported; physical/fullscreen projector work remains v2.01.

Persistent EditorSession edits record complete copy-on-write model/media snapshots. Undo restores geometry, masks, source/target/clip identities, group membership/maps/joins, libraries/tags, reference settings, content and audio/brightness configuration. Mapping/mask drags and saved-setting sliders use explicit continuous transactions. New/Open/recovery clear history; Save retains it. Runtime transport, selection, calibration, guides, fades, blackout, audio enablement and frames remain outside edit history. Native text editing uses field-editor undo; toolbar Edit acts on the project.

History has a 100-step cap, conservative per-snapshot image/encoded/poster charges capped at 256 MiB, and distinct retained video originals capped at 2 GiB. A notice records pruning. These bounds do not claim a cap on total model/AVFoundation/GPU/process memory. Imported and reopened videos are staged separately; saved-package replacement cannot remove media retained by history. Unadopted native Open/recovery stages are removed, and shutdown/New/replacement release managed files. Same-ID media relinks have runtime content revisions so unchanged dimensions/names still dirty the project and undo restores original bytes. Save snapshots retain the revisions captured at save start; history is session-only.

Readiness is an explicit bounded snapshot (maximum 200 displayed issues with total counts/omission notice). It checks geometry/input maps/masks/joins, referenced media including looks/clips/reference photos, metadata/files/poster inspection, codec/range/package validation, reported decoder problems, audio device and output scope. Blockers, warnings and information are distinct. Reports do not play/seek/arm audio or promise performance. Temporary selected-owner white identification filters the render-only scene, preserving saved project, transport and original calibration. Finish remains in the status bar; blackout still wins.

Timeline control/clip-editor rows scroll horizontally on narrow windows. Saved-setting sliders have accessible labels and coherent history. Help supplies Welcome, Guide and protected demo opening; About states Test Mode accurately. The generated app icon is included in the asset catalog. The bundled portable demo contains an original house illustration/reference with a masked house, three connected faces, timed effect/image/video blocks and an independent looping video. It is an illustration, not a photographic/automatic mapping claim. Each demo opening generates a new project ID, protects unsaved work and requires Save As to a personal location.

Use the Release command in BUILD_AND_RUN.md with universal ARCHS/ONLY_ACTIVE_ARCH settings. For the sustained workload, select only VideoTests/runningLoopStressProfileAndPortableDemo(), set TEST_RUNNER_PROJECTION_MAPPER_VIDEO_PROFILE_HD=1, TEST_RUNNER_PROJECTION_MAPPER_VIDEO_PROFILE_SECONDS=60 and TEST_RUNNER_PROJECTION_MAPPER_VIDEO_EVIDENCE_OUTPUT to an existing fresh output directory.
