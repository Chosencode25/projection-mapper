# Demo media

The current protected demo is maintained once in
`app/ProjectionMapper/ProjectionMapper/Resources/V1-Demo.projectionmap`.
Use **Help → Open V1 Demo** to open an unsaved copy without changing the original.
Tests use that same bundled fixture. The earlier video/timeline example remains here
as a distinct project fixture, not an older application build.

`assets/local-projects/` holds projects rescued from old build folders during cleanup.
These are local-only working files, excluded from Git. Do not delete them with build caches.
